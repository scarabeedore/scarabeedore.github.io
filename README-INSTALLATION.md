# Site Scarabée Doré — index réécrit

Cette version est une vitrine statique pour GitHub Pages. Elle présente l’accompagnement professionnel, la méthode ÉLYSCA, les séances, les formations et le livre.

## Structure

- `index.html` : page d’accueil et présentation de l’activité.
- `mentions-legales.html` : page à compléter avec les informations exactes de l’entreprise et de l’hébergeur avant publication.
- `confidentialite.html` : politique à adapter aux traitements réellement utilisés.
- `style-legal.css` : styles des pages légales.
- `assets/` : logo.

## Avant publication

Complétez les mentions entre crochets dans les pages légales : identité et adresse professionnelle, SIRET/RNE, e-mail, téléphone, hébergeur, TVA si applicable, médiateur de la consommation si vous contractez avec des consommateurs, ainsi que vos durées réelles de conservation.

L’index ne contient ni paiement, ni formulaire, ni outil de mesure d’audience. Les échanges commencent par e-mail ; les prix, modalités, conditions d’annulation et documents contractuels sont communiqués avant tout engagement.

Le site n’utilise pas de police distante ni de cookie non nécessaire.
